Активация почты для формы «Мой ответ»

Эта страница нужна один раз. Она отправляет на сервис FormSubmit обычную (не фоновую) заявку — после этого сервис присылает на адрес ilyamironu@mail.ru письмо с кнопкой подтверждения. Пока письмо не подтверждено, формы на сайте будут отвечать «Сервис отправки недоступен»: это и есть незавершённая активация.

Шаг 1. Нажмите кнопку ниже

Если появится проверка «Я не робот» — пройдите её. После отправки откроется страница сервиса FormSubmit — это нормально, ничего больше делать не нужно.

Шаг 2. Подтвердите письмо

Откройте почту ilyamironu@mail.ru (обязательно проверьте папку «Спам»). Придёт письмо от FormSubmit с кнопкой Activate Form — нажмите её и увидите сообщение об успешной активации.

Шаг 3. Проверьте тихую (фоновую) отправку

Нажмите кнопку ниже — она делает ровно такой же фоновый запрос, как формы на сайте, и показывает ответ сервиса. Если в ответе есть "success":"true" — всё работает и страницы сайта снова отправляют ответы незаметно, без перезагрузки.

Ответ сервиса появится здесь.

Шаг 4. Что дальше

После успешной проверки файл activate.html можно удалить — на работу сайта он не влияет и из меню он не доступен. Если позже поменяете почту в js/config.js, активацию нужно будет пройти заново для нового адреса.
