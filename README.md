# Навигатор — «Три бесплатных урока» (клон сайта для GitHub Pages)

Точная копия сайта `sites.google.com/view/navigator-3uroka` в виде обычных статических
файлов. Открывается быстро и без VPN, все тексты перенесены дословно, ссылки на
библейские стихи открываются **во всплывающем окне** (никаких переходов на сторонние
сайты), а под каждым вопросом урока есть кнопка **«Оставить ответ»**.

---

## 2. Как посмотреть локально

Проще всего — открыть `index.html` двойным щелчком.
Если нужно проверить отправку форм, лучше запустить локальный сервер
(двойной щелчок не всегда разрешает отправку данных):

```powershell
powershell -ExecutionPolicy Bypass -File ".build\serve.ps1"
```

затем откройте в браузере `http://localhost:8080/`.

## 3. Публикация на GitHub Pages (через браузер, без программ)

1. Зайдите на **github.com** → **New repository**.
   Имя, например: `navigator`. Тип — **Public** (для бесплатных GitHub Pages нужен
   публичный репозиторий). Нажмите **Create repository**.
2. На странице пустого репозитория: **Add file → Upload files**.
3. Перетащите мышью **всё содержимое** папки `Проект`, кроме папки `.build`:

   * файлы: `index.html`, `vozmozhno-li-zhit-vechno.html`, `urok-1.html`, `urok-2.html`,
     `urok-3.html`, `uznat-bolshe.html`, `404.html`, `robots.txt`, `.nojekyll`, `README.md`
   * папки целиком: `css`, `js`, `assets`

   > Перетаскивайте именно **папки** (`assets`, `css`, `js`) — тогда GitHub сам
   > разложит файлы по нужным путям. Ограничение GitHub при загрузке через браузер —
   > 25 МБ на файл; самое большое видео у нас ~5 МБ, всё проходит.
4. Внизу нажмите **Commit changes**.
5. **Settings → Pages** → в разделе *Build and deployment*:
   * Source: **Deploy from a branch**
   * Branch: **main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты сайт будет доступен по адресу:

   ```
   https://<ваш-логин>.github.io/<имя-репозитория>/
   ```

   Этот адрес и кодируйте в QR-код. Если позже добавите фотографии — просто повторите
   загрузку (Upload files) и сделайте коммит, адрес не изменится.

## 4. Как включить приём ответов («Мой ответ» → на почту)

Отправка идёт без своего сервера, через бесплатный сервис **FormSubmit** (ключ не нужен —
он уже прописан).

1. Откройте сайт и отправьте любой тестовый ответ (напишите «тест») с любого вопроса.
2. На адрес `ilyamironu@mail.ru` придёт письмо от FormSubmit с заголовком
   **Activate Form** — нажмите в нём кнопку подтверждения.
3. Готово: после этого все ответы читателей будут приходить вам на почту.

Каждое письмо содержит: анонимный номер («Читатель #4821»), страницу, урок, вопрос,
текст ответа, контакт для связи (если он указан) и дату отправки.

* Сменить почту: `js/config.js` → строка `EMAIL`.
* Другой сервис (Web3Forms): получите бесплатный Access Key на https://web3forms.com,
  затем в `js/config.js` укажите `PROVIDER: "web3forms"` и вставьте ключ в `ACCESS_KEY`.
  **`js/config.js` — единственный файл, куда нужно что-то вставлять.**

Приватность: при первом заходе в localStorage создаётся только анонимный номер вида
«Читатель #4821» (чтобы связать ответы одного человека с разных абзацев). Никаких cookie,
счётчиков, аналитики и персональных данных. Поле «Контакт для связи» — необязательное.
Если сервис отправки окажется недоступен, форма предложит ссылку «Отправить письмо вручную».

## 5. Фотографии

Фотографии **уже на месте** — 9 штук в папке `assets/img/`. Скачать их с Google Sites
не удалось (сервер отдавал ошибку 403), поэтому они взяты с ваших же страниц на
telegra.ph — там опубликованы те же материалы. Соответствие «файл ← откуда взято»
описано в `assets/img/SOURCES.txt`.

Два замечания:

* у страницы УРОК №1 в оригинале было три фотографии, здесь две: третья ссылка и на
  самом telegra.ph ведёт на несуществующий файл (битая);
* картинка-обложка («Навигатор») с Google Sites недоступна, поэтому шапка сайта
  оформлена фирменным цветом с градиентом, как на оригинале.

Если захотите заменить или добавить фото — просто положите файл с нужным именем
(`urok1-2.jpg`, `urok3-4.jpg` и т. д.) в `assets/img/`. Если файла нет, пустое место
автоматически убирается, текст и видео не страдают.

## 6. Что нужно знать про содержимое

* все тексты перенесены дословно, включая особенности оригинала (в уроке 1 нумерация
  идёт 1, 2, 4 — пункт «3.» в оригинале отсутствует; «Урок 01», «Урок 02», «Урок 03»);
* 40 библейских текстов открываются во всплывающем окне из `js/verses.js` — это те же
  тексты, что были по ссылкам на ваши страницы telegra.ph (переходов на внешние сайты нет);
* два стиха — «1 Петра 3:15» и «Матфея 10:8» — на оригинале приведены без текста,
  поэтому для них подставлен Синодальный перевод (в окне честно указано
  «Синодальный перевод (проверьте у себя)») — при желании замените текст в `js/verses.js`;
* ссылка «телеграмм @wkondrw» на странице «Узнать больше» оставлена ведущей на ваш
  собственный адрес `navigator-duh.rostdavid.workers.dev`, как в оригинале;
* стих «ПСАЛОМ 21:27» на оригинале был разорван ссылкой («ПСАЛОМ 21:2» + «7») —
  здесь это одна аккуратная ссылка;
* кнопка «Начать интерактивный библейский курс» ведёт на урок 1, кнопка «Начать» —
  на страницу «Возможно ли жить вечно?» (как в оригинале);
* `robots.txt` и `<meta name="robots" content="noindex, nofollow">` отключают индексацию
  поисковиками — это соответствует блоку «Информация для читателей». Если хотите,
  чтобы сайт находился в поиске, удалите `robots.txt` и строки с `noindex` в страницах.

## 7. Как что-то поправить

* текст урока — в соответствующем `.html`-файле;
* текст стиха — в `js/verses.js` (запись `"ключ": { ref, text, src }`);
* почта и ключ сервиса — в `js/config.js`;
* цвета и оформление — в `css/style.css` (в начале файла переменные `--plum` и `--pink` —
  фирменные цвета, взятые с оригинала).
